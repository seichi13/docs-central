# Análisis de Causa Raíz (RCA)

Un RCA (Root Cause Analysis) es un método estructurado para identificar la causa fundamental de un problema. : **los 5 porqués**.

El objetivo es solucionar la fuente del conflicto en lugar de simplemente tratar los síntomas, evitando así que los fallos vuelvan a ocurrir.

## ¿Cuándo escribir un RCA?

Debe escribirse un RCA en los siguientes casos:

- **Incidentes críticos**: Fallos que afectan a la producción o servicio
- **Problemas recurrentes**: Cuando el mismo problema ocurre múltiples veces
- **Errores de seguridad**: Vulnerabilidades o brechas de seguridad
- **Impacto significativo**: Situaciones que generan pérdidas económicas o de datos
- **Cambios fallidos**: Despliegues o cambios que causaron problemas inesperados
- **Quejas de clientes**: Problemas que afectan la experiencia del usuario
